# 出生海滩与营地布局方案

从南岸进入营地时，小屋、果树、矿机光柱和远处神殿同时出现在竖屏里。营火位于营地东侧，水台和箱子也在它南边不足四米处。经营板、订单板、无线电和矿机挨在营地北侧，容易从同一位置够到多个互动目标。

```text
                         北 · 内陆
       果树成簇            经营区 · 告示板、矿机
  小屋 / 床                工坊 · 工作台、箱子
                     营火               支路 → 溪流
                     入营路
  西南码头 ← 支路     漂流物 → 出生点
                         南 · 海滩
```

1. 出生海滩留一条通往营火的视线。漂流物沿路分散，路两边用少量树丛收边。营火承担近处导航，矿机和神殿留在第二视线层。
2. 营火前留步行和转身空间。小屋、床和箱子组成生活区，工作台靠生活区外侧。净水台放在通往溪流的支路口。经营和通讯设施放到火塘后方，两个板靠边摆放，面朝来路。
3. 树木成簇，组与组之间留可通过的空隙。优先调整挡住营地入口及前景的树和石头。掉落资源仍沿关键路线可达。
4. 首批先清入营通道，其次拆开经营设施的互动范围。移动功能物件时同步共享锚点、碰撞、阴影、距离判定和任务指引。现有玩家建设和存档作为回归场景。

验收机位为出生正视、营地入口以及营火向码头回看。逐个确认视线、行走路线和互动目标，核对触屏选中与就近互动是否一致。布局为草案，坐标由实际碰撞和真机画面决定。
