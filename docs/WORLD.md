# CastawaySOL 世界观圣经 v1.0（2026-11-02 用户批准定版；分叉 A 按 A1 活矿物暂行，B 先民去向不锁死，C 岛名暂定晶雾岛——三项用户均可改）

## 一句话
一座被晶石共振场藏起来的海岛：漂流到此的人靠先民留下的共振技术把晶石变成活下去的资本，最后不是逃出去，而是把营地建成一个家。

## 一、岛
- 暂名「晶雾岛」。母晶的共振场扰乱罗盘与无线电，雾带常年环绕——船只漂得进来，却找不到出去的航道。外界地图上没有这座岛。
- 出路只有两条，都是工程：修好船并等晶场潮汐的平静窗口；或点亮灯塔，在窗口期引航。两条线都通向同一个结局方向：你可以选择离开，但故事不替你选——无结局经营的支点在此：主角选择留下，身份从漂流者变成建岛者。
- 岛上没有原住民村落。只有先民遗迹（神殿、传送门）和历代漂流者的小营地。

## 二、晶石（分叉点 A，待裁定）
晶石是全岛生态与经济的根：会发出可感知的共振「嗡鸣」，老漂流者称晶脉的活动为「岛在呼吸」。母晶是全岛晶脉的根，埋在岛心，周期性的共振潮汐决定了母晶池的涨落（玩法映射：母晶池/爆池）。
- A1【主控荐】活矿物：地脉与海底热泉共同长出的活矿物，会自己生长、互相共振；先民只是发现并利用了它。
- A2 天外陨晶：远古陨星带来，岛本身就是陨坑隆起，晶石是外来物。
- A3 人造能源：晶石是先民文明制造的能源载体，文明消失后失控野长成今天的晶脉。

## 三、先民
- 先民是先于所有漂流者居住在岛上的文明，掌握共振技术：神殿传送门是他们的共振装置，矿机的原理也源于他们的遗存（由雷蒙德复原图纸）。
- 先民整体消失，去向不明——是长线悬念：传送门通向哪里、先民是离开了还是变成了什么。只给线索，不急着揭晓。
- 先民审美即全岛遗迹与道具的设计母语：圆润的石构、悬浮晶、苔痕。

## 四、人
- 主角：船难漂流者，开局一无所有。
- 艾莉：更早的漂流者后代，在岛上长大，是主角认识岛的窗口（她对晶雾和动物习性最熟）。
- 雷蒙德：研究晶石共振的学者，乘的考察船同样沉没；他复原先民技术，是矿机与扫描仪的来源。
- 其他营地的漂流者不直接登场，他们的存在通过共振勘探体现：勘探本质上是全岛营地共享同一条晶脉的开采，份额按各营地的投入分配（UI 上的「模拟矿工」是合规标注，世界观内即其他营地）。

## 五、动物（特有种总则，2026-11-02 用户定）
- 岛上动物都是历代随船、随洋流漂来的物种后代，与世隔绝后在晶场环境里演化出特有适应——设计任何动物先写一句「它在岛上演化出了什么」，再谈造型。
- 已定三例：苔背猴（与苔藓共生）、沙洲犬（掘沙铲爪/芭蕉叶耳）、晶芽羊（羊毛里长晶芽）。
- 规律：离母晶越近的区域，动物越奇异。岛心深处有受共振影响最深的晶兽——未来的野怪与 Boss 从这里出，奇异度随深入递增。

## 六、玩法与世界观的映射（防止数值与叙事脱节）
- 矿机：先民共振提炼装置的仿制品，把原晶提炼成稳定的能量晶片。
- 算力代币（sol_token）：漂流者营地之间通用的记账单位，以精炼晶片计价——世界观内它只是岛内通货，与任何现实货币无关。
- 共振勘探：共享晶脉开采，见「四」。
- 母晶池与潮汐：见「二」。
- 食物与生存：岛的生态自给（果树、渔获、净水），生存系统是经营的燃料而非主线压力源——与已定的「挖矿为核心、生存为远征燃料」一致。
- 船的等级：从漂流木筏到能冲出雾带的船，代表活动半径扩大（近岸→礁湖→邻岛）。

## 九、群岛扩展（2026-11-02 用户定：后续要扩展其它岛屿）
- 晶雾岛只是「雾环群岛」中的一座。整片群岛都躺在同一个巨型晶脉系上，被同一片雾带藏着；每座岛有一颗自己的母晶，强弱不同、地貌与生态各异。
- 每座岛是一套独立的特有种生态：同一祖先漂到不同岛上、演化出不同形态（加拉帕戈斯逻辑）——这是后续岛屿的内容引擎：换岛 = 换生态、换动物、换晶石品类、换先民遗迹风格。
- 岛与岛之间靠三样东西连通，全部受共振潮汐制约：船（活动半径随船等级扩大：近岸→礁湖→邻岛）、灯塔链（点亮一座，安全航道多一段）、先民传送门网（后期快速通道，门与门相连，修一座通一座）。
- 扩展顺序按半径自然展开：主岛经营立住 → 礁湖小岛（资源岛）→ 邻岛（新生态+新营地）→ 群岛深处（母晶源头/先民之谜）。

## 十、玩家联动（每位玩家 = 群岛中一座岛的岛主）
世界观内每位玩家都是同一片群岛里另一座岛的漂流者兼建岛者。岛屿彼此隔绝于外界、却被晶脉共振连在一起——联动全部走这条「共振网络」，叙事与系统同构：
- **共振共享（核心联动）**：共振勘探的晶脉本就贯通群岛，份额池天然是全玩家共享的。当前版本由模拟矿工填充，联动版逐步换成真实玩家的投入——同一套 UI、同一套规则，填充物从模拟变真人。这是单机转联动的主桥，不推翻现有设计。
- **潮汐信标与漂流瓶**：玩家可以把补给、图纸、话留进潮汐信标，随共振潮汐漂到别人的岛上（异步馈赠/留言）。
- **拜访与来访**：别人的船会在潮汐窗口造访你的岛（留影式拜访：看、留礼、交易，不改你的岛）；你也可以出海拜访邻岛玩家的岛。
- **岛间贸易**：各岛物产不同（呼应群岛生态差异）， surplus 资源通过信标市场互通有无——贸易是生态差异的必然结果，不是外挂的商城。
- **全网事件**：共振大潮汐（全群岛母晶池联动爆发）、灯塔链共修（所有玩家共同点亮航线）、雾季（季节性全球目标）——个人进度汇入全网进度。
- **名人堂与灯塔光**：母晶名人堂全网可见；夜里海面上能看见邻岛玩家的灯塔光束（轻量存在感，不要求实时同屏）。
- 分期口径：单机版先行（联动以世界观接口预留）；**联动核心已定（2026-11-02 用户）：玩家同场押「晶脉频率」**——全网统一轮次时钟、同池同时揭晓，频率层叠加在现有矿脉格上（格有频段归属、押格即押频），模拟矿工只作冷启动填充并随真人占比退场；信标/拜访/贸易/名人堂为辅助层；实时同岛协力仍押后。细则见设计要点（主控工作区 resonance-multiplayer-frequency.md）。

## 七、与现实层的隔离（红线）
- SKR / Solana 元素只存在于游戏外层（皮肤、赛季结算、展示），世界观内绝不出现加密货币、钱包、收益率概念。
- 游戏内不承诺任何现实收益；概率与规则公示义务按既有合规设计执行。
