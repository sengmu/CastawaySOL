# 荒岛求生与群岛扩张玩法方案 v1

日期：2026-10-31。方向已获用户认可；具体数值、节奏、配方和规则细节是建议，需原型验证。

## 定位与循环

亲自操控角色在荒岛求生，通过打捞、建设、救援建立基地，再出航开发邻岛，形成自己的群岛区域，后续合作与争夺。

短缺 → 探索打捞 → 运回资源或幸存者 → 建造与岗位分配 → 稳定生产 → 准备出航 → 开发新岛 → 回流稀缺资源 → 扩建防御。

前期亲手解决吃喝，中期居民接管重复劳动，后期聚焦探索、运输、布局和争夺。基地稳定后应减少频繁点击吃喝的负担。

## 宣传式成长要真实可玩

漂流物可见可拾取，钩索和自动打捞后续解锁；建筑显示轮廓、材料需求、完成过程并产生实际作用；幸存者有发现、救回、安置、分工过程；居民能看见搬运和工作。修桥、码头、浮台改变可到达范围。风暴造成可预测可准备的损失。每次重要升级都有场景或行为变化，不用等待计时和动画冒充玩法。

## 扩张尺度

1. 岛内：清理障碍扩大可建区，搭建连接海岸的平台和码头。
2. 邻岛：修船、航行、解决当地障碍、建前哨、运入补给，获得归属。
3. 区域：维护补给与航线，争夺资源节点，发展群岛领地。

自然陆地不靠花木材凭空长大。首版不做任意填海。主岛是长期家园；木材岛提供木材；矿石岛支持工具与设施升级；前哨提供补给侦察；争夺岛后续提供稀缺资源。占领应改变资源和航行选择，不能只有地图变色。

## 资源与设施

基础资源：树枝/木材（树木、漂流、木材岛）、果实/椰子/鱼（采集垂钓）、淡水（采集或净水）、纤维/绳索（植物加工）、废金属/零件（箱子沉船）、石料/矿石（岩石矿岛）。先统一现有ID，避免重复材料命名。

设施：营火、净水设施、储物箱、床位、工作台、码头、前哨。逐项定义输入、输出、容量、放置范围、操作和状态。未确定最终消耗数值。建设校验真实库存，失败/取消/重复点击不能重复扣费或复制物品。

## 居民生产

初期岗位为打捞员、生产员、建造员，先实现一个真实岗位再增加。救人增加劳动力，也增加床位和饮食需求。供应不足降低效率并提示原因；首版不做离线饿死和永久失去居民，不做抽卡星级。
同一居民不能同时多岗位。生产与消耗使用统一模拟时间。离线收益与结算上限另行设计，未实现前不得宣称已有。

## 剧情改造

主线从逃离荒岛改为建立家园、发现群岛。收音机解锁救援信号、事件和海域线索；木筏解锁首次出航；SOS吸引补给/幸存者；第二幸存者成为第一名可分配居民；猴子作为探索辅助；宝石成为后期支线。
任务记录真实行动或持久里程碑，不能靠开局赠送物品和初始数值自动完成。事件只更新相应条件，任务系统检查当前目标，禁止不相关事件直接advanceStep。合成物品只解锁能力，不直接通关。

## 前30分钟目标体验

时间只是体验目标，不是硬倒计时或工期。
- 0–5分钟：移动、采集、进食、补水，解决第一次短缺。
- 5–10分钟：打捞、建营火储物，形成营地。
- 10–15分钟：收集零件建净水设施，稳定水源。
- 15–20分钟：救回幸存者，安置并分配岗位。
- 20–25分钟：准备补给修木筏，开放邻岛海图。
- 25–30分钟：开发木材岛、建前哨、回运资源并扩建家园。
先核查地图可获得物资再删体验物品，每个必需配方都必须有可达来源。

## 多人边界（未实现）

先做小规模限时据点占领，再考虑运输护送、海战、联盟。失败可损失本次携带物资或据点控制权，默认不清空长期家园。

### 核心转折

修好收音机后，玩家没有立即获救，而是收到附近岛屿幸存者断续的求救。第一次对外出航用于救人。救援归来后人口增加，营地供给不足，由此推动净水设施、居民生产与资源岛开发。

为避免流程依赖死锁：原主岛第二幸存者可先承担基础救助教学；第一名正式岗位居民可来自首次外岛救援，或使用主岛幸存者先解锁最低限度分工。具体人物映射实施前确定，不能同时要求“先救居民才能造船”和“先造船才能救第一名居民”。首次出航必须能靠玩家手动采集准备完成。

净水设施首次建造教学可在出航前进行；救援归来的短缺应推动扩容与稳定生产，不能在同一任务线重复宣称第一次解锁净水。

### 三类目标

- 主线任务：引入系统，记录真实操作，如首次救助、首次修船、首次出航。
- 发展目标：玩家自主选择，如增加床位、稳定供水、开发木材岛；不必全部串成强制线性章节。
- 探索支线：猴子、遗迹、宝石等故事与特殊奖励。除明确设计的解锁外，不阻断日常经营。

任务事件更新对应里程碑，任务系统判定当前步骤；合成收音机和木筏只解锁能力，不直接结算胜利。救人、建造不能跳过不相关任务。

### 后期逃脱选择

原逃脱结局可保留为后期目标：完成远程通讯或远航准备后选择离开，或者留下建设。结局记录阶段旅程，结算后仍可继续经营。它不再是首次修好收音机或木筏后的强制终点。具体解锁条件与离开后的叙事需后续设计。

### 首版叙事骨架

海难求生 → 营地安身 → 修复通讯 → 收到求救 → 准备航行并救回同伴 → 扩大生产 → 开发邻岛。

此骨架统领剧情节奏；前述前30分钟时间表是原型建议，如人物、净水和出航顺序出现冲突，以无死锁、可真实操作和本节衔接规则为准，实施时同步修订目标清单。
