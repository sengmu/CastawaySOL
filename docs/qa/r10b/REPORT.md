## 200k 轮实测

每项策略连续结算 200,000 轮，固定确定性种子，计入主池、残晶、母池、保底。混合时段沿用原 sim 的 dawn/day/day/dusk/night；均匀时段为四时段等权。实机没有时段自动推进，初始 day，睡醒固定 sunrise，因此分别验证两者，不能用混合均值掩盖晨曦失败。天气沿用 clear/clear/cloudy/rain/typhoon。

| NPC 系数 | 晨曦中性 | 台风夜间完美信息 + 蟹煲 |

| 0.50 | 0.759450765 | 1.069246420 |
| 0.45 | 0.762268807 | 1.092688625 |
| 0.55 | 0.757033483 | 1.048572317 |
| 0.60 | 0.754929612 | 1.030243223 |

0.50 的三项裁定指标：
- 中性：混合 0.792848710；实机初始白天 0.781577451；睡醒晨曦 0.759450765（失败）。
- 夜×台风中性 0.917214135 / 四时段均匀中性 0.795933704 − 1 = 15.237504%（失败）。
- 全部策略最大值至少 1.069246420（台风×夜×完美信息×蟹煲，失败见证；未冒充全矩阵精确最大值）。蟹煲以连续三轮有效窗口重复采样，每个测量轮均带 buff，不摊薄其收益。

0.45 已违反最优上限；0.50、0.55、0.60 已违反实机中性下限，故无候选能同时满足要求。失败候选无需继续全矩阵才能判定不合格。候选探针见 candidate-probe.mjs，实测见 candidates.jsonl；主 sim 在中性/择时红线失败时直接非零退出，见 sim-050.log。
