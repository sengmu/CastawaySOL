# 矿机界面一页化研究（2026-11-03，用户令「好好设计，游戏感更强，一个页面显示，不要滚动」）

## 一、现状盘点（解密页签，竖屏 390×844 实测）

弹窗可用高 736px，内容实际约 1100px+，必须滚动。七个纵向堆叠块：
页签行+升级钮 → 英雄看板（状态/算力/进度条/3 指标瓦）→ 增压卡 → 装填卡 → 蓄能卡 → Solana 存证卡。
轮2 已解决配色（奶油化），没解决信息架构：**它是一张表单，不是一台机器**——所有状态都是文字行，没有一样东西"长在机器身上"；主操作（猛击摇动）埋在第二张卡里；存证卡这种低频功能占了一整块黄金位置。

共振页同样超一页（网格在、操作行沉到滚动边缘）；母晶池账本列表天然会长。

## 二、参考拆解（点名具体做法）

- **RollerCoin**：矿机是房间里的实体机器，算力 = 机器本体，升级 = 换更大的机器。"机器即界面"。
- **Dome Keeper**：穹顶与钻机本体占画面主体，状态围着机器长，操作即游戏画面。
- **Forager**：建筑面板紧凑单屏，大图标大按钮，无长列表。
- **增量游戏（Mr. Mine / Tap Titans 类）**：一个巨大的主按钮 + 跳动的数字是全屏主角，其余强化围着它一屏排完。
- 共性：**主体是一台看得见的机器；状态长在机器身上（槽位亮灭、电量格、核心发光）；操作钮围着机器排；一屏完结。**

## 三、方案：「矿机驾驶舱」一页定版

信息分三层，全部功能保留，只重排与降级低频项：

### 主角层（约 40% 高）——机器本体
- 黏土风矿机插画居中（太阳能板 + 发光晶核 + 底座，与游戏内矿机模型同款造型），状态直接长在机器上：
  - **核心光环** = 当前区块进度（环形进度绕核心走），替代现在的细进度条；
  - **晶仓槽位** = 机器侧面 10 个实体槽，装几块亮几块（替代"晶石装载 1/10"文字）；
  - **电池格** = 机器顶部粗电池 5 格亮灭（替代"蓄电池储能 75%"文字）；
  - **算力大数字**压在机器基座上（30px 表格数字，可滚动 ticker）；
  - 状态一句话进机器头顶气泡（全速运算中 / 待料中 / 狂暴超频）。
- 动效：核心呼吸脉冲；狂暴时整机转橙 + 脉冲加速；**出块瞬间核心爆闪 + 「出块 +2」浮字**；装填时槽位逐个点亮。

### 操作层（约 30%）
- 左：黄色大主钮 **猛击摇动**（本页唯一黄钮），带连击计数火焰徽章，连击越高越"热"；
- 右两列：装填 1 块 / 填满矿仓；
- 下一排：蓄能三图标钮（电池 / 树液 / 树枝，带库存角标），56px 起、胖钮厚度带、按压回弹 + 震动（HapticFeedback 已有）。

### 信息带（约 15%，底部一条）
已验证区块 #N · 累计产出 ｜ 待出块产出（>0 时该格变黄色「收获」钮）｜ 升级矿机（象牙，带消耗数）｜ **Solana 存证降为一枚小芯片**，点开才展开存证卡——低频功能不再占主页整卡。增压/蓄能的解释性长文案删除或改长按提示。

### 其余页签同守一页纪律
- 页签行保留顶部（四签一行放得下）。
- 共振页：状态条 + 5×5 网格（格 52px）+ 已选信息 + 操作行 ≈ 一页（现已接近，压缩状态条即可）；模拟矿工披露原文保留在状态条下。
- 母晶池：池额英雄卡 + 账本只列最近 3 条 + 名人堂前 3 名，全量收进「展开全部」。
- 概率公示：双列紧凑表，行高压缩，一页放完；数字仍走 ODDS_TABLE 单一数据源。

### 形态建议：顺势改全屏页
矿机是核心玩法，值得整页：竖屏预算（844 全屏）标题+页签 96 / 机器区 330 / 操作区 190 / 信息带 84 / 间距余量 ~140，宽裕达标；继续用底部抽屉（736）也能塞下但机器区要压到 280。横屏（390 高）：左半机器、右半上操作下信息带。
关闭回 HUD 的行为不变；事件绑定沿用现有 id，渲染函数只重排结构、不动数值与逻辑。

## 四、红线（与历轮一致）

模拟矿工披露原文不动；赔率与一切数字不动；ODDS_TABLE 单一数据源；账本枚举不动；奶油黏土语言与体积标准（主钮 ≥96、辅钮 ≥52、厚度带、字号 ≥12）不回退。
