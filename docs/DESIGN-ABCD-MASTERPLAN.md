# CastawaySOL 功能完善四大专题工程定稿（A → B → C → D）

> 状态：全部审阅确认定稿（2026-11-03）
> 适用范围：主线 0~6 章叙事引导、群岛外岛终局生态、移动端触屏营建与工坊深度化、第 6 章自由经营长线驱动体系

---

## 一、全局红线与架构约束

1. **经济与合规红线**：
   - 游戏内算力代币 `sol_token` 与真实 `SOL`、Seeker 生态代币 `SKR` 严格分离展示，不得混称，不承诺任何现实收益；
   - 高纯精炼纯晶 `sol_crystal_pure` 严禁通过真实货币或 `SKR` 购买；
   - **R3 差分隔离**：所有真实 `SOL` 商业化特权对 `sol_crystal` 产出速率与赛季共振声望 `RS` 的影响严格等于 `0`，且真实 `SOL` 消费绝不调用 `onSinkSpent` 注入母晶池；
   - `ODDS_TABLE` 保持单一数据源且赔率数值不改动，`EconomyLedger` 冻结枚举不违规扩改，保留“本地模拟矿工（非真人联机）”披露原文；
   - 本地存档、本地探索图鉴与本地荣誉头衔不得包装为服务端联机、云存档或链上 NFT；不得恢复合成木筏或收音机直接通关的旧版逃脱捷径。
2. **资产冻结与存储约束**：
   - `Nin_NX_NVN` 前缀 DAE 模型资产处于冻结态，严禁新增任何引用，新增 3D 场景与工坊设施统一使用 Three.js 程序化低多边形黏土几何体构建；
   - 临时目录与 Android 构建缓存一律置于 `E:\CastawaySOL` 下，不在 C 盘写入构建产物。
3. **测试兼容约束**：
   - 保持 `StorySystem.chapters` 7 章 15 个步骤的 `id` 与 `type` 结构稳定，确保 `verify-m1-story-skeleton.mjs`、`verify-m2-story-events.mjs` 与 `verify-mainline-spine.mjs` 全绿兼容。

## 二、专题 A：主线 0~6 章叙事与引导全闭环重构

### A1. 收音机配方唯一化与纯晶精炼闭环
- **废弃电池收音机旁路**：从 `CraftingBlueprints.js` 与 `CraftingSystem.js` 移除 `workradio_battery`（破损收音机 + 蓄电池），保留唯一正统配方 `workradio`（`sol_crystal_pure x1 + broken_radio x1`），确保第 3 章必须走通纯晶精炼主干。
- **补齐纯晶精炼炉 UI 入口**：针对 `CampFacilitiesSystem.buildRefinery()` 无前端入口导致第 5 章北崖灯塔死档的问题，在 `UIManager.openCampManageModal` 增设【纯晶精炼炉】建造（L1：原木×4 + 碎石×4 + 铁锭×2）/ 升级（L2：木板×4 + 铁锭×3 + 算力代币×20）及【一键划转待炼原料入储物箱】（硅晶原石×2 + 松脂×1）操作卡。

### A2. 过章里程碑前置可视化与递进横幅
- 在 `StorySystem` 新增 `getChapterGateChecklist(chapterId)`，实时返回当前章节过章硬门槛的逐项完成态（例如第 2 章：安装扫描仪 Mk1 + 完成共振结算；第 3 章：建造纯晶精炼炉 + 修复高频收音机；第 4 章：修缮船坞远航浮木岛营救雷蒙德；第 5 章：集齐三梯晶石点亮北崖灯塔一期）。
- `getQuestBannerText()` 在章节常规步骤走完但过章硬门槛未满足时，自动切换为未完成项的精确行动指引，杜绝横幅卡死笼统提示。

### A3. 后山神殿三宝石封印门禁
- 新增持久化布尔状态 `templeUnsealed = false`（若老档已持有 `poseidon_crown` 或 `templePuzzle.puzzleSolved === true` 则自动兼容置为 `true`）。
- 玩家首次走近后山神殿大门时，检验背包/储物箱是否集齐 `star_gem`、`diamond_gem`、`moon_gem` 三枚圣石；集齐后触发解封演出永久开启神殿大门（不消耗三宝石原件或按神殿镶嵌标记永久留存），未集齐时给出三枚圣石的方位线索。

### A4. 居民作息坐标校准与旧版逃脱文案清理
- 修正 `VillagerManager.js` 中艾莉与学者雷蒙德的四时段驻留坐标至西南主营地有效陆地范围（`Z ≈ 15.5 ~ 36.8`），消除 NPC 站在北侧树林无人区的问题。
- 全面清理 `CraftingBlueprints.js`、`StorySystem.js`、`UIManager.js` 等处残留的“逃离荒岛/直升机救援通关”旧文案，统一收束为“群岛定居、开拓航海与点亮北崖地脉灯塔”世界观。

## 三、专题 B：群岛航海终局补完——第 3 外岛与外岛动态生态

### B1. 第 3 外岛【晶雾回声岛】（`mist_reef_isle`）与双锁引航
- 在 `NauticalChartSystem` 注册第 3 座可航行外岛 `mist_reef_isle`（航程 `12.8km`，基础单程消耗饮水 4 / 食物 4，T3 铁甲远洋探索舰远洋补给全免）。
- **双锁开启条件**：北崖灯塔一期已点亮（`lighthouse.isLit === true`）且船坞已升级至 T3 探索舰（`shipUpgradeSystem.currentTierLevel >= 3`）。
- **修复 T3 自动拖网缺陷**：将 `ShipUpgradeSystem.onVoyageCompleted()` 中稀有海产由误配的 `'diamond_gem'` 修正为 `'pearl'`（天然珍珠），并在外岛航行结算时正式挂载调用。

### B2. `MistReefIsleScene` 场景、跨天再生与第 3 前哨站
- 新建纯程序化低多边形场景 `src/island/MistReefIsleScene.js`：
  - 核心采集物：`sol_crystal_deep` ×2、`copper_ore` ×2、`sol_crystal` ×1（走 `EconomyLedger` 的 `vein_mine` 入账）、`pearl` ×1、首次登岛保底 `treasure_map_piece` ×1；
  - 交互地标：【晶雾观测前哨站】（每日自动回运 `sol_crystal_deep ×1` 或 `copper_ore ×1` + `pearl ×1` 至营地储物箱）与【先民潮汐传送残阵】（供专题 D 灯塔二期贯通传送网）。
- **三座外岛分级跨天再生与满包入船仓**：
  - 将外岛 `collectedResourceIds` 升级支持记录采集天数 `resourceCooldowns: { [id]: respawnDay }`（兼容老档数组自动迁移）；
  - 普通木材/礁石 `+2 天` 再生，铁矿/铜矿/珍珠 `+3 天` 再生，深层海脉晶核 `+4 天` 再生；
  - 外岛采集时若玩家随身行囊格满，自动转存入 `shipUpgradeSystem` 随船货仓并弹出提示。

### B3. 外岛特有种演化晶兽与石碑联动
- 依据 `docs/WORLD.md` 第五节设定，在 `WildlifeCombatSystem` 扩展外岛局部守护兽（击败后 `+2 天` 再生）：
  - 浮木岛：【沉船寄居蟹】（掉落 `crab`、`wood_plank`）；
  - 矿石岛：【玄武岩甲蜥】（正面近战减伤 30%，引导绕侧攻击，掉落 `iron_ore`、`stone_chunk`）；
  - 晶雾回声岛：【晶簇棱背蟹】（周期蓄力环形震波红圈预警，击败掉落 `sol_shard` 走 `resonance_shard` 入账及 `crab`）。
- **矿石岛石碑持久化联动**：`QuarryIsleScene.readMonolith()` 新增持久化 `monolithRead = true`，解锁大本营耐火锻造熔炉的青铜船板配方。

## 四、专题 C：营地建造触屏重构与工坊生产深度化

### C1. 移动端触屏网格建造闭环
- **双入口**：在【营地告示板】顶部增设 `营地规划与建造` 按钮，并在主岛 HUD 工具区提供 `营建` 快捷入口（进入外岛或神殿室内时自动隐藏并退出建造态）。
- **分类营建栏与联合扣料**：底部提供 `功能设施 / 休憩家具 / 照明与景观` 三分类抽屉，建造扣料自动合并扣减“随身背包 + 营地储物箱”。
- **触屏瞄准、四重合法性光圈与编辑回收**：
  - 默认吸附玩家前方 `2.2m`（`0.5m` 网格对齐），同时支持触屏点击/拖拽地面移动预览；
  - 脚底绿/红光圈实时校验：海拔入水与坡度、家具间距 `< 1.2m`、核心世界锚点 `2.5m` 禁建保护圈（主帐篷、矿机、告示板、祭坛、码头船只、神殿门扉）、材料充足度；
  - 悬浮操作条支持新建态 `左旋 90° / 右旋 90° / 确认放置 / 退出`，以及点选已有设施后的 `移位 / 旋转 90° / 拆卸（100% 返还建材，带非空容器防丢物保护）`。

### C2. 家具存档失忆修复与 `SaveSystem` 单一数据源收口
- 新增 `hydrateFurnitureMeta()`，按 `id` 从资产表与程序化设施表回填 `isBed`、`isStorage`、`isWaterPurifier`、`isFurnace`、`isRefinery`、`comfortScore`、`cost`，根治读档后床位数归零与净水台失效缺陷。
- 在 `BuildSystem` 实现 `serialize()/deserialize()`，由 `SaveSystem.applyDataToGame()` 统一接管恢复（兼容迁移旧 `castaway_island_furniture_v2`），并在 `clearSave()` 时同步清理旧键。

### C3. 工坊双炉程序化 3D 实体与高温冶炼管线
- **纯晶精炼炉实体（`crystal_refinery`）**：纯 Three.js 低多边形构建 L1 石砌坩埚炉与 L2 双腔石英导流塔，炉火随待炼库存动态亮灭，走近打开单屏【纯晶精炼面板】（与告示板入口双向同步）。
- **耐火锻造熔炉交互接通（`furnace`）**：纳入 `getNearestInteractable()`，走近打开单屏【耐火冶炼面板】，提供 3 条高温配方：
  1. `铁矿石×1 + 树枝×1 → 精炼铁锭×1`（支持 `×1 / ×5` 批量冶炼）；
  2. `黄铜矿×2 + 松脂×1 → 沉船金属板×1`（矿石岛 `monolithRead` 解锁）；
  3. `海滩浮木×2 + 碎石×1 → 应急电池×1`（生物质热电转化消纳过剩浮木）。

### C4. 营地舒适度（Camp Comfort）轻量化增益
- 按营地内**不重复家具种类**计分（满分 100，分 Lv.1~Lv.4 四档）：
  - Lv.2（≥20 分）：睡眠额外恢复 `+15` 生命、疲劳额外多减 `15` 点；
  - Lv.3（≥50 分）：居民排班采集普通木材/石块/浆果额外产出率 `+15%`；
  - Lv.4（≥80 分）：每日清晨储物箱获赠居民手制早点 1 份。
- 严格遵循 R3 隔离：对 `sol_crystal` 产出、纯晶日产能上限、矿机算力与 `RS` 影响严格为 `0`。

## 五、专题 D：终局自由经营（第 6 章）长线驱动体系

### D1. 北崖灯塔二期（星海谐振塔）与先民三点传送网
- 前置：第 5 章灯塔一期已点亮且持有 `poseidon_crown`。
- 交付：`sol_crystal_pure: 4` + `sol_crystal_deep: 3` + `pearl: 2` + 共鸣归位 `poseidon_crown: 1`。
- 效果：灯塔升起双环星冕棱镜与极光双光束；激活 **【主岛先民祭坛】⇄【后山神殿内殿】⇄【晶雾回声岛·潮汐传送残阵】** 零补给三点瞬移；海皇圣物归位使远航耗水减半并提升捕鱼稀有海产率（对 `sol_crystal` 与 `RS` 零影响）。

### D2. 荒岛博物图鉴与先民编年史（`CodexSystem.js`）
- 分为 `生态与海产卷（12项）`、`地质与晶脉卷（10项）`、`群岛异兽卷（5项）`、`先民遗迹碑文卷（5项）` 共 4 卷 32 项本地探索档案，支持老档状态自动回溯点亮。
- 分卷满收集奖励依次为：储物箱容量 `+10` 格、赠送 `crab_pot ×2`、近战武器耐久损耗 `-25%`、解锁完整群岛编年史与【群岛守望者】本地头衔。

### D3. 晶脉棋盘（共振页）战术交互升级与矿机升级恢复
- 不改动 `ODDS_TABLE` 任何参数与模拟矿工披露原文，严格保持单屏留白：
  1. 在共振页状态栏外显引擎原生 `crab_pot`（暴击表增益）与 `energy_drink`（扫描仪临时 +1 级）状态芯片，支持背包持有时一键饮用；
  2. 将 `autoSplitEven()` 升级为热脉高 EV 优先智能均分（已装扫描仪时优先挑选热脉候选格中实时 EV 最高的前 `k` 格平铺）；
  3. 恢复矿机解密驾驶舱底部紧凑【升级矿机 L2~L4】按钮与章节图纸门禁提示。

### D4. 第 6 章远洋订单扩充与全勤料理闭环
- 第 6 章起在 `OrderBoardSystem` 动态并入黄铜矿、深层晶核、天然珍珠高阶订单（走 `order_deliver` 记账），支持“背包 + 储物箱”联合履约；当日 3 单全部完成后额外获赠【船长全勤餐盒】（`crab_pot ×1` 或 `energy_drink ×1`），闭环反哺高阶共振勘探。
